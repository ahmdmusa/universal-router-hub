## 5. Store Review Justification for Permissions

* **Permission: `storage`**:
  > Used exclusively to store user UI preferences locally (language choice, theme, font scaling, quota renewal day, and optional saved router credentials for 1-click convenience). No data ever leaves the local browser profile.
* **Host Permissions: `http://192.168.*`, `https://192.168.*`, `http://10.0.0.*`, `https://10.0.0.*`**:
  > Required to inject the modern dashboard and communicate via local HTTP/HTTPS requests with the router's internal web server gateway at standard local subnets (192.168.1.1, 192.168.0.1, 10.0.0.1).
